# 1. 사이버폭력 — 중학생이 정점인 문제

## 실제 데이터
- **청소년 42.7%** 가 사이버폭력 경험 (성인 13.5%). 전년 대비 1.9%p 증가 — 2024년 사이버폭력 실태조사, 방통위·NIA
- 가해·피해 모두 **남성·중학생·20대**에서 가장 많음. **언어폭력**이 최대 비중
- 청소년 **18.6%** 가 디지털 혐오표현을 사용한 적 있음
- 청소년 **16.1%** 가 디지털 성범죄를 목격
- 학교폭력 유형 중 **사이버폭력 7.8%로 증가세**, 집단 따돌림 16.4%도 증가 — 2025년 1차 학교폭력 실태조사, 교육부
  (언어폭력·신체폭력은 감소하는데 **따돌림·사이버폭력만 증가**)

## 안 풀린 문제 목록
1. 피해자가 **증거를 남기는 방법을 모른다** — 캡처하는 순간 상대가 삭제하거나, 캡처가 조작으로 몰린다
2. **단톡방 따돌림은 욕설이 없다.** 읽씹, 초대 후 즉시 퇴장, 특정인만 뺀 방 개설, 답장만 안 하기 → 기존 필터링은 전부 못 잡는다
3. 신고하면 **가해자에게 신고 사실이 알려질까 봐** 못 한다
4. 목격자(방관자)가 개입할 **낮은 비용의 방법이 없다** — 편들면 다음 표적이 된다
5. 혐오표현을 쓴 본인이 **그게 혐오표현인 줄 모른다** (밈·은어로 유통)
6. 삭제된 대화는 사라지지만 **캡처는 영원히 돈다**
7. 신고 창구가 기관별로 흩어져 있어 **어디에 신고해야 하는지 모른다**

## 아이템 후보
| 아이템 | 핵심 |
|---|---|
| **단톡방 소외 탐지기** | 욕설이 아니라 **패턴**을 본다. 특정인 발언 후 응답률, 초대/퇴장 로그, 대화 참여 비율 → "이 방에서 A는 발언 후 평균 응답이 0.2건" |
| **증거 보존 도우미** | 캡처에 타임스탬프·해시 자동 삽입. 조작 아님을 증명하는 구조 설명이 발표 포인트 |
| **방관자 원클릭 지지 버튼** | 공개 반박 대신 **피해자에게만 보이는 익명 지지 신호**. 개입 비용을 낮춘다 |
| **혐오표현 자가진단 사전** | 내가 쓰는 밈이 어디서 왔고 누구를 겨냥하는지 알려주는 위키 |
| **신고 창구 길찾기** | 상황 3문항 → 학교/117/경찰/플랫폼 중 어디로 갈지 안내 + 필요한 준비물 |

# 2. 스마트폰 과의존 — 청소년이 전체 평균의 2배

## 실제 데이터
- 전체 과의존 위험군 **22.7%**, **청소년(10~19세)은 43.0%** — 2025년 스마트폰 과의존 실태조사, 과기정통부
- 전체는 5년 연속 하락하는데 **청소년만 증가** (+0.4%p)
- 서울 청소년 **10명 중 4명**이 과의존 위험군 — 삼육대 서울 청소년 디지털정신건강 실태조사
- 인터넷·스마트폰 과다사용으로 일상에 지장받는 초4·중1·고1 학생 **213,243명** — 2025년 여가부 미디어 이용습관 진단조사

## 안 풀린 문제 목록
1. 기존 차단 앱은 **부모가 설치하고 자녀가 뚫는** 대결 구도 → 신뢰만 깨진다
2. **사용시간 총량은 의미가 없다.** 3시간 공부 영상과 3시간 숏폼은 같은 3시간으로 집계된다
3. 스크린타임 숫자를 봐도 **행동이 안 바뀐다** (인식과 행동의 간극)
4. 끊긴 집중이 **회복되는 데 걸리는 시간**은 아무도 안 센다
5. 알림의 대부분은 **나중에 봐도 되는 것**인데 전부 즉시 알림이다
6. 자기 전 사용이 수면을 갉아먹는데, **수면 부족은 다음날 자제력을 또 떨어뜨린다** (악순환)
7. "줄이자"는 목표만 있고 **대체 행동**이 없다

## 아이템 후보
| 아이템 | 핵심 |
|---|---|
| **알림 부검 일지** | 하루 알림을 "필요했다/나중에도 됐다/필요 없었다"로 분류 → 주간 리포트 → 끌 알림 추천. *"내게 진짜 필요한 알림은 12%였다"* 같은 문장이 나온다 |
| **콘텐츠 질 가중 스크린타임** | 시간이 아니라 **무엇을 봤는지**로 점수. 본인이 직접 카테고리 태깅 |
| **인식-실제 격차 트래커** | 자기 전 "오늘 몇 시간 썼을 것 같나" 입력 → 실제와 비교. 격차 그래프가 곧 결과물 |
| **집중 회복시간 측정기** | 탭 전환 시각 기록 → 다시 몰입까지 걸린 시간 추정 |
| **자기 협상 앱** | 부모가 아니라 **본인이 미리 규칙을 정하고 미래의 자신과 계약**. 손실 회피 대신 복구 가능 설계 |

# 3. 청소년 정신건강·수면 — 여학생이 특히 위험

## 실제 데이터 (2025년 청소년건강행태조사, 질병관리청)
- 우울감 경험률 **남 21.7% / 여 29.9%**
- 스트레스 인지율 **남 32.9% / 여 50.3%** — 여학생 절반
- 주중 평균 수면시간 **남 6.6시간 / 여 5.9시간**
- 주관적 수면충족률 **남 28.3% / 여 16.9%** — 여학생 6명 중 1명만 "잘 잤다"

## 안 풀린 문제 목록
1. 수면시간을 재는 앱은 많지만 **왜 못 자는지**를 묻는 도구는 없다
2. 우울·스트레스 자가진단은 **점수만 주고 끝난다** — 그다음에 뭘 해야 하는지가 없다
3. 상담 문턱: 상담실 들어가는 걸 **누가 볼까 봐** 못 간다
4. 도움을 요청하는 **말을 모른다** ("힘들다"고 어떻게 말하지)
5. 친구가 힘들다고 할 때 **뭐라고 답해야 하는지 모른다** → 어설픈 위로가 오히려 상처
6. 여학생 스트레스가 남학생의 1.5배인데 **원인 분해 데이터가 없다**
7. 시험기간·수행평가 몰림과 정신건강의 **시기적 상관**을 학교가 안 본다

## 아이템 후보
| 아이템 | 핵심 |
|---|---|
| **수면 방해요인 로그** | 시간이 아니라 **원인**을 기록 (숙제/영상/불안/소음/카페인) → 개인별 1순위 방해요인 도출 |
| **말 빌려주기 카드** | 지금 감정에 맞는 문장을 골라 그대로 보낼 수 있게. "도움을 요청하는 언어"를 제공 |
| **친구 응답 가이드** | 친구가 힘들다고 할 때 하면 안 되는 말/해도 되는 말 3장 카드 |
| **학사일정-스트레스 상관 대시보드** | 우리 반 익명 스트레스 지수 × 수행평가 일정 겹쳐 그리기 → **학교에 제안하는 자료**가 된다 |
| **익명 온도 체크** | 최소 응답수 미만이면 결과 비공개. 개인 특정 불가 설계 자체가 발표 포인트 |

# 4. 고령층 디지털 격차 — 초고령사회의 일상 마비

## 실제 데이터
- 고령층 디지털정보화 수준 **71.4%** — 취약계층 중 최하위 (2024 디지털정보격차 실태조사)
- 55세 이상 중 키오스크 사용 경험 **약 52%**, 그중 **약 60%가 불편 경험** (서울시복지재단)
- 불편 이유: **"뒤에 사람이 있어서 눈치 보임", "옵션 적용이 어려움", "용어가 어려움"**

## 안 풀린 문제 목록
1. **뒷사람 눈치** — 기술 문제가 아니라 **시간 압박이라는 심리 문제**다. 아무도 이걸 안 푼다
2. 키오스크마다 **버튼 위치와 용어가 전부 다르다** (표준 없음)
3. "테이크아웃/포장", "샷 추가", "적립" 같은 **용어 자체를 모른다**
4. 실패하면 **처음부터 다시** — 되돌아가기가 없거나 숨어 있다
5. 연습할 곳이 없다. **실전이 곧 첫 시도**다
6. 은행·병원·행정 앱은 **인증 단계에서 좌초**한다 (공동인증서, 본인확인, OTP)
7. 도움을 청할 대상이 **가족뿐**이고, 가족은 대신 해주고 만다 → 학습이 안 일어난다

## 아이템 후보
| 아이템 | 핵심 |
|---|---|
| **키오스크 연습장 웹** | 실제 프랜차이즈 화면을 본뜬 **연습 모드**. 틀려도 되고 뒤에 아무도 없다. ← 가장 강력한 아이템 |
| **키오스크 용어 사전** | 사진 찍으면 화면 속 용어를 큰 글씨로 풀어줌 |
| **한 화면 한 동작 리모컨** | 스마트폰을 초대형 버튼 3개짜리로 바꾸는 웹앱 |
| **인증 절차 지도** | "병원 예약"까지 가는 데 필요한 단계를 미리 그림으로 보여주는 안내도 |
| **가르치는 법 가이드** | 손자녀용. **대신 해주지 않고 가르치는** 5단계 |

# 5. 사회적 고립·고독사 — 노인만의 문제가 아니다

## 실제 데이터
- 2024년 고독사 사망자 **3,924명** (전년 3,661명 대비 **7.2% 증가**) — 보건복지부
- 인구 10만 명당 **7.7명** (전년 7.2명)
- **50~60대 중장년 남성**이 가장 취약
- **여관·모텔·고시원** 발생 비중이 5년째 증가
- 1인 가구 비율 **36.1%** (2024)
- 2026년부터 정부 대상이 **"사회적 고립 위험군"** 으로 확대 — 청년까지 포함

## 안 풀린 문제 목록
1. 고독사는 **죽음의 문제가 아니라 단절의 문제**다. 단절은 훨씬 전에 시작된다
2. **안부 확인이 감시처럼 느껴진다** → 거부당한다
3. 이상 징후는 이미 **데이터로 존재한다** (전기·수도 사용, 우편물, 배달 이력) 그런데 연결이 안 된다
4. 청년 고립은 **통계에도 안 잡힌다** (사망해야 세어진다)
5. 도움을 받는 것이 **낙인**이 된다
6. 고시원·모텔 거주자는 **주소지 기반 복지망 밖**에 있다
7. 이웃이 이상을 느껴도 **어디에 알려야 할지 모른다**

## 아이템 후보
| 아이템 | 핵심 |
|---|---|
| **감시 아닌 안부 앱** | 위치·건강 추적 없이 **"오늘 문 열었음" 버튼 하나**. 이틀 없으면 지정인에게 알림. 프라이버시 최소 수집 설계가 발표의 핵심 |
| **무소음 이상징후 체크** | 본인이 정한 신호(전등 켬, 우편함 확인 체크)만 사용 |
| **동네 느슨한 연결망** | 친밀함이 아니라 **약한 유대**를 설계 — 인사만 하는 관계 목록 |
| **청년 고립 자가진단** | "최근 2주간 누군가와 15분 이상 대화한 날이 며칠인가" 같은 **행동 기반** 문항 |
| **이웃 신고 길찾기** | 이상 징후 목격 시 어디에 연락할지 안내 |

# 6. 노인 보행 안전 — 보행 사망자의 3분의 2

## 실제 데이터 (2024년, 경찰청·도로교통공단)
- 전체 교통사고 사망자 **2,521명** (12년 연속 감소, 역대 최저)
- 그런데 **보행자 사망자는 920명으로 3.8% 증가**
- 보행 사망자 중 **65세 이상이 67.0%(616명)** — 전년 62.1%에서 급증
- 고령자 10만 명당 교통사고 사망률 **15.1명 = OECD 평균(6.8명)의 2.2배**

## 안 풀린 문제 목록
1. 신호 시간이 **평균 보행속도 기준**이다. 노인은 못 건넌다 → 무단횡단으로 분류된다
2. 무단횡단으로 집계되는 사고 중 상당수가 **횡단보도가 너무 멀어서** 생긴다
3. 야간 시인성: 어두운 옷 + 가로등 부재 + 운전자 시야
4. 위험 지점은 **주민이 다 아는데 데이터로 안 남는다**
5. 보행 신호 잔여시간 표시가 없는 곳이 여전히 많다
6. 실버존이 지정돼 있어도 **운전자가 인지 못 한다**

## 아이템 후보
| 아이템 | 핵심 |
|---|---|
| **우리 동네 건너기 어려운 횡단보도 지도** | 직접 스톱워치로 **신호 시간 vs 실제 통과 시간** 측정. 노인 10명 실측 데이터 = 강력한 증거 |
| **횡단보도 없는 구간 제보 지도** | 사람들이 실제로 건너는 지점을 표시 → 시설 요구 자료 |
| **야간 시인성 자가 점검** | 옷 색·반사재 유무로 인지 거리 시뮬레이션 |
| **보행 신호 여유시간 계산기** | 내 걸음 속도 입력 → 이 횡단보도를 건널 수 있는지 판정 |

# 7. 다문화·언어장벽 — 학생 25명 중 1명

## 실제 데이터 (2025년 교육기본통계, 교육부)
- 다문화 학생 **202,208명 = 전체 학생의 4.0%**
- 국내출생 136,592명(67.6%) / **외국인가정 52,876명(26.1%)** / **중도입국 12,740명(6.3%)**
- 중도입국·외국인가정 급증을 **KSL(제2언어로서 한국어) 교육과정이 못 따라감**
- 이중언어 코치 210명·언어발달 지도사 330명 vs 기초지자체 약 230개 → **지자체당 1~2명**
- 부모와 모국어를 함께 쓰는 가정이 **40% 미만** → "두 언어 모두 서툰" 상태로 입학

## 안 풀린 문제 목록
1. **생활 한국어는 되는데 교과 한국어가 안 된다** ("직각", "가정법", "이등변" 같은 학습 어휘)
2. 가정통신문·급식표·수행평가 안내가 **한국어 단일 언어**
3. 통역은 상담 때만 오고 **수업 중에는 없다**
4. 또래가 도와주고 싶어도 **뭘 모르는지 모른다**
5. 중도입국 학생은 **학년은 맞는데 언어는 초1 수준** → 어느 교실에서도 안 맞는다
6. 모국어를 유지할 이유를 아무도 말해주지 않는다 → **두 언어 모두 잃는다**

## 아이템 후보
| 아이템 | 핵심 |
|---|---|
| **교과 어휘 카드** | 국어·수학·과학 교과서에서 뽑은 **학습 어휘**를 그림+모국어로. 생활 번역기와 차별화되는 지점 |
| **가정통신문 다국어 변환기** | 사진 찍으면 OCR → 쉬운 한국어 + 주요 언어 요약 |
| **또래 도우미 체크리스트** | "지금 이 학생이 막힌 지점"을 짚어주는 진단 문항 |
| **모국어 자랑 아카이브** | 반 친구들의 모국어 인사·속담·음식 아카이브 — 낙인을 자산으로 뒤집는 설계 |

# 8. 음식물 쓰레기 — 학교 안에서 매일 발생하는 데이터

## 실제 데이터
- 경기도 초·중·고 2,533개교 급식 잔반 **연 61,561톤**, 처리비용 **연 109억 원**
- 대구 431개교 연간 음식물쓰레기 **9,300여 톤**, 학교당 연평균 **21,600kg**
- 광주·전남 일부: 연 **575만 kg**, 처리비용 **11억 7천만 원**
- 잔식 기부 시행 후 1인 1식 잔반 **231g → 223g** (처리비 44.7원 → 42.8원)

## 안 풀린 문제 목록
1. **얼마나 버리는지 학생이 모른다.** 총량만 있고 개인·학급 피드백이 없다
2. 배식량이 **전원 동일**하다 — 적게 먹는 학생도 같은 양을 받는다
3. 인기 없는 메뉴가 **매년 반복 편성**된다 (선호 데이터가 급식실로 안 간다)
4. 남길 걸 알면서도 **미리 덜어놓을 방법이 없다**
5. 잔반 감축 캠페인은 **죄책감에만 의존**한다 → 오래 안 간다
6. 잔식 기부는 제도가 있어도 **학교가 방법을 모른다**

## 아이템 후보
| 아이템 | 핵심 |
|---|---|
| **메뉴별 잔반 예측·투표판** | 내일 메뉴 사전 투표 → 예상 잔반 → 실제와 비교. **급식실에 제출하는 리포트**가 산출물 |
| **배식량 사전 선택** | 등교 시 "많이/보통/적게" 선택 → 급식실 집계 |
| **우리 반 잔반 그램 대시보드** | 학급 단위 무게 측정 → 주간 그래프. 개인 아닌 학급 단위라 낙인 없음 |
| **메뉴 조합 추천** | 잔반 데이터로 "이 반찬은 이 밥과 나올 때 덜 남는다" 도출 |

# 9. AI 시대의 진짜/가짜 — 지금 가장 신선한 주제

## 실제 상황
- 생성형 AI로 만든 이미지·목소리·영상이 **구별 불가 수준**에 도달
- 청소년 **16.1%가 디지털 성범죄를 목격** (딥페이크 포함)
- 학교 현장에서 지인 합성물 사건이 사회 문제화
- 한국코드페어 제8회 주제가 아예 **"AI와 데이터로 해결하는 우리 사회의 문제"**

## 안 풀린 문제 목록
1. **피해자가 유포를 멈출 방법이 없다** — 신고해도 재유포
2. 무엇이 AI 생성물인지 **표시할 의무가 없다**
3. 학생들이 **"장난"과 "범죄"의 경계를 모른다**
4. 목격자가 **어디에 신고할지 모른다**
5. AI가 쓴 글을 판별한다는 도구들이 **오탐이 심하다** → 억울한 학생이 생긴다
6. 과제에서 AI 사용의 **허용 범위가 학교마다 다르고 명문화돼 있지 않다**

## 아이템 후보
| 아이템 | 핵심 |
|---|---|
| **AI 사용 라벨 표준 제안** | "AI 100% / AI 보조 / 사람 100%" 배지를 만들어 이미지에 합성해주는 웹 + 우리 학교 규약 초안 |
| **딥페이크 대응 절차 카드** | 피해 발생 시 1시간 안에 할 일 5단계 (증거보존→신고처→삭제요청→상담) |
| **"이건 장난인가 범죄인가" 판별 퀴즈** | 실제 사례 기반 시나리오. 법적 결과를 함께 표시 |
| **우리 학교 AI 사용 가이드라인 초안** | 과제 유형별 허용 범위를 학생이 직접 설계해 학교에 제안 |

# 10. 주제 고르는 기준표

| 기준 | 확인 방법 |
|---|---|
| 숫자가 있는가 | 위 데이터처럼 **공식 통계 1개**를 인용할 수 있는가 |
| 사용자가 가까운가 | 오늘 5명에게 보여줄 수 있는가 |
| 남들이 안 건드린 각도인가 | "차단" 말고 "지연", "총량" 말고 "질", "시간" 말고 "원인" |
| 데이터를 내가 만들 수 있는가 | 2주 기록·설문 30명으로 성립하는가 |
| 판정 기준을 한 문장으로 말할 수 있는가 | "응답률 0.2건 미만이면 소외 신호" 처럼 |

## 이 문서에서 가장 승산 높은 5개 (주관적 추천)
1. **키오스크 연습장** — 심리적 문제(눈치)를 기술로 푼 유일한 접근. 사용자 확보도 쉬움(가족)
2. **단톡방 소외 탐지** — 욕설 필터가 못 잡는 영역. 데이터 42.7%가 뒷받침
3. **알림 부검 일지** — 만들기 쉽고(★★) 결과가 숫자로 나옴. 청소년 43% 통계 인용 가능
4. **횡단보도 신호시간 실측 지도** — 스톱워치만 있으면 됨. 67% 통계가 강력
5. **급식 잔반 예측·투표판** — 학교에 실제로 제출 가능한 리포트가 나옴. 연 109억 원
