# 아이템 30선 — 고르기 위한 목록

> 앞선 [큰주제_문제목록_아이템찾기.md](큰주제_문제목록_아이템찾기.md)의 문제 목록에서 **실제로 만들 수 있는 것만** 30개로 압축.
> 정렬: **추천 순위**. 1~10번이 승산이 가장 높다.
> 각 항목 = `문제 근거(공식 통계) · 만드는 것 · 남들과 다른 점 · 데이터 확보 · 난이도`
> ★=반나절 ★★=주말 ★★★=1~2주

## TIER 1 — 가장 승산 높은 10개

### 1. 키오스크 연습장
- **근거**: 55세 이상 키오스크 사용자의 **약 60%가 불편 경험**. 1순위 이유가 **"뒤에 사람이 있어서 눈치 보임"** (서울시복지재단)
- **만드는 것**: 실제 프랜차이즈 화면을 본뜬 연습 모드 웹. 타이머 없음, 뒷사람 없음, 무한 재시도
- **다른 점**: 다들 "쉬운 UI"를 만들 때 이건 **심리적 압박을 제거**한다. 기술 문제가 아니라 시간 압박 문제라는 재정의가 핵심
- **데이터**: 조부모·부모 5명 실측 (성공률·소요시간 전후 비교)
- **난이도**: ★★

### 2. 단톡방 소외 탐지기
- **근거**: 청소년 **42.7%** 사이버폭력 경험, **중학생이 정점**. 학교폭력 중 **집단 따돌림·사이버폭력만 증가** (2025 교육부)
- **만드는 것**: 대화 붙여넣기 → 특정인 발언 후 응답률, 초대·퇴장 로그, 발언 점유율 → 소외 지표
- **다른 점**: **욕설이 없는 따돌림**을 잡는다. 기존 필터링 앱이 전부 놓치는 영역
- **데이터**: 본인 동의 받은 단톡방 or 시나리오 생성 데이터
- **난이도**: ★★

### 3. 알림 부검 일지
- **근거**: 청소년 스마트폰 과의존 **43.0%** — 전체 평균 22.7%의 2배 (2025 과기정통부)
- **만드는 것**: 하루 알림을 "지금 필요 / 나중에도 됨 / 필요 없음"으로 분류 → 주간 리포트 → 끌 알림 추천
- **다른 점**: 차단이 아니라 **분류**. *"내게 진짜 필요한 알림은 12%였다"* 라는 문장이 발표를 끌고 간다
- **데이터**: 본인 3일 + 친구 5명
- **난이도**: ★★

### 4. 건너기 어려운 횡단보도 지도
- **근거**: 보행 사망자의 **67%가 65세 이상**(616명). 고령자 사망률 **OECD 평균의 2.2배** (2024 경찰청)
- **만드는 것**: 스톱워치로 신호 시간 vs 실제 통과 시간 측정 → 부족한 지점 지도화
- **다른 점**: 앱보다 **실측 데이터가 주인공**. 노인 10명 실측이면 구청 제출 자료가 된다
- **데이터**: 직접 측정 (장비 = 스톱워치)
- **난이도**: ★★

### 5. 급식 잔반 예측·투표판
- **근거**: 경기도 초·중·고 잔반 **연 61,561톤 / 처리비 109억 원**. 대구 학교당 연 **21,600kg**
- **만드는 것**: 내일 메뉴 사전 투표 → 예상 잔반 → 실제 무게와 비교 → 급식실 제출용 리포트
- **다른 점**: 죄책감 캠페인이 아니라 **급식실에 넘길 데이터**를 만든다
- **데이터**: 나이스 급식 API(무료) + 우리 반 투표 + 저울
- **난이도**: ★★

### 6. 수면 방해요인 로그
- **근거**: 여학생 주중 수면 **5.9시간**, 수면충족률 **16.9%** — 6명 중 1명만 "잘 잤다" (2025 질병관리청)
- **만드는 것**: 수면 '시간'이 아니라 '원인'을 기록 (숙제/영상/불안/소음/카페인) → 개인별 1순위 방해요인
- **다른 점**: 수면 트래커는 많지만 **왜 못 자는지 묻는 도구는 없다**
- **데이터**: 본인 2주 + 반 친구 10명
- **난이도**: ★★

### 7. 감시 아닌 안부 앱
- **근거**: 고독사 **3,924명 (+7.2%)**, 1인 가구 **36.1%**, 2026년부터 대상이 **사회적 고립 위험군**으로 확대 (보건복지부)
- **만드는 것**: 위치·건강 추적 없이 **"오늘 문 열었음" 버튼 하나**. 이틀 무응답 시 지정인 알림
- **다른 점**: 안부 확인이 감시로 느껴져 거부당하는 문제를 **최소 수집 설계**로 푼다. 프라이버시 설계 자체가 발표 포인트
- **데이터**: 가족·이웃 3명 2주 시범
- **난이도**: ★★

### 8. 교과 어휘 카드
- **근거**: 다문화 학생 **202,208명 = 전체 4.0%**. 중도입국 12,740명. 이중언어 지도인력이 **지자체당 1~2명** (2025 교육부)
- **만드는 것**: 교과서에서 뽑은 **학습 어휘**(직각·이등변·가정법)를 그림 + 모국어로
- **다른 점**: 번역기는 생활 한국어를 처리한다. **교과 한국어**를 다루는 게 빈 자리
- **데이터**: 교과서 어휘 직접 추출 + 대상 학생 인터뷰
- **난이도**: ★★

### 9. 앱 권한 번역기
- **근거**: LG AI 청소년 캠프 3기 실제 프로젝트 계열. 삼성 주니어 SW 중등부 수상작이 전부 이 계열(개인정보·악플)
- **만드는 것**: 앱이 요구하는 권한 목록 → "이 손전등 앱이 왜 연락처가 필요한가?" 중학생 언어로 해석 + 위험 점수
- **다른 점**: 권한 목록은 공개돼 있는데 **아무도 안 읽는다**. 해석을 붙인다
- **데이터**: 스토어 공개 권한 정보
- **난이도**: ★★

### 10. AI 사용 라벨 배지
- **근거**: 청소년 **16.1%가 디지털 성범죄 목격**. 한국코드페어 제8회 주제가 **"AI와 데이터로 해결하는 사회 문제"**
- **만드는 것**: "AI 100% / AI 보조 / 사람 100%" 배지를 이미지에 합성해주는 웹 + 우리 학교 규약 초안
- **다른 점**: 규제를 요구하는 대신 **작은 표준을 직접 만들어 배포**한다
- **데이터**: 학급 규약 설문
- **난이도**: ★★

## TIER 2 — 확실하지만 무난한 10개

### 11. 방관자 원클릭 지지 버튼
사이버폭력 목격자가 공개 반박 없이 **피해자에게만 보이는 익명 지지**를 보내는 기능. 개입 비용을 낮춘다. ★★

### 12. 증거 보존 도우미
캡처에 타임스탬프·해시 자동 삽입 → 조작이 아님을 증명. 피해자가 증거 남기는 법을 모른다는 문제. ★★

### 13. 신고 창구 길찾기
상황 3문항 → 학교/117/경찰/플랫폼 중 어디로 갈지 + 필요한 준비물 안내. 창구가 흩어져 있는 문제. ★

### 14. 인식-실제 격차 트래커
자기 전 "오늘 몇 시간 썼을 것 같나" 입력 → 실제와 비교. **격차 그래프 자체가 결과물**. ★★

### 15. 학사일정 × 스트레스 상관 대시보드
여학생 스트레스 인지율 **50.3%**. 우리 반 익명 스트레스 지수에 수행평가 일정을 겹쳐 그림 → **학교에 제안하는 자료**. ★★

### 16. 익명 온도 체크
"이 상황 불편한 사람?"을 익명 집계해 **분포만** 공개. 최소 응답 수 미만이면 비공개 — 개인 특정 불가 설계가 발표 포인트. ★★

### 17. 가정통신문 다국어 변환기
사진 → OCR → 쉬운 한국어 + 주요 언어 요약. 다문화 가정 4.0% 통계 뒷받침. ★★

### 18. 커브컷 지도 (계단 없는 길)
경사로는 휠체어만을 위한 게 아니다 — 유모차·캐리어·배달카트가 쓴다. 경로 제보 + 수혜자 태깅. ★★

### 19. 배식량 사전 선택
등교 시 "많이/보통/적게" 선택 → 급식실 집계. 전원 동일 배식이라는 구조 문제를 건드린다. ★★

### 20. 야간 시인성 자가 점검
옷 색·반사재 유무로 운전자 인지 거리 시뮬레이션. 노인 보행 사망 67% 통계와 연결. ★★

## TIER 3 — 각도가 신선한 10개

### 21. 모둠 기여도 3모드 기록판
같은 데이터를 **균등 / 투입시간 비례 / 결과 기여 비례** 세 기준으로 계산 → 모드마다 다른 결론. "공정이란 무엇인가"가 UI가 된다. ★★

### 22. 계획 오류 트래커
과제 시작 전 예상시간 vs 실제시간 기록 → 개인 보정계수(예: 1.7배) 산출 → 다음부터 자동 보정. 사용자·데이터·결과가 전부 자급자족. ★★

### 23. 지표 왜곡 시뮬레이터
"독서 권수로 평가하면 얇은 책만 읽는다"를 슬라이더로 조작해 보여줌. 데이터 수집 부담 0인데 통찰이 크다. ★★

### 24. 댓글 3초 지연 장치
공격적 표현 감지 시 "이 말을 얼굴 보고 할 수 있나요?" + 3초 대기. 기존 수상작이 전부 '차단'인데 이건 **'지연'**. 전송률 변화를 친구들과 실험. ★★

### 25. 보이지 않는 일 로그
가족·팀 안에서 티 안 나는 일만 기록 → 월말 파이차트. **각자에게 "내 기여 %"를 물으면 합이 100을 넘는다** — 이 그래프 한 장이 발표를 끌고 간다. ★★

### 26. 추천 피드 다양성 지수
하루 동안 뜬 추천 영상 제목을 손으로 기록 → 주제 분포 → "내 세계는 얼마나 좁은가". 2주 개입 후 변화 측정. API 없이 성립. ★★

### 27. 학급 규칙 합의 도구
찬반이 아니라 **"내가 못 받아들이는 정도" 0~5**로 표시 → 총 반대강도가 최소인 안 채택. 다수결의 한계가 그대로 UI. ★★

### 28. 공용물 상태 기록판
마지막 사용자·상태를 남기면 다음 사람이 본다. **익명일 때 vs 기록될 때** 2주 비교 실험이 진짜 결과물. ★★

### 29. 디지털 발자국 자가진단
내 이름·아이디로 남아 있는 흔적을 **본인이 직접** 점검하는 체크리스트. 대행하지 않는 설계가 윤리적으로도 안전. '지우개 서비스'(만24세 미만) 연결. ★★

### 30. 딥페이크 대응 절차 카드
피해 발생 시 1시간 안에 할 일 5단계 — 증거보존 → 신고처 → 삭제요청 → 상담 → 심리지원. 목격자용 버전 별도. ★

## 고르는 법

**3개로 좁히는 질문**
1. 이 문제를 **내가 직접 겪었거나 가족이 겪는가?** → 발표 첫 30초가 결정된다
2. 사용자 5명을 **이번 주에** 만날 수 있는가? → 같은 반, 가족, 동네
3. 판정 기준을 한 문장으로 말할 수 있는가? → "응답률 0.2건 미만이면 소외 신호"

**조합 추천 (대회별)**
| 대회 | 어울리는 번호 |
|---|---|
| LG AI 청소년 캠프 (AI 활용 필수) | 2, 3, 8, 9, 20, 24 |
| 디미고 창업아이디어 (사업화 20점) | 1, 5, 8, 17, 18, 19 |
| 한국코드페어 (사회문제·연구성) | 4, 6, 7, 15, 26, 28 |
| 발명·과학 계열 | 1, 4, 19, 20 |

**가장 만들기 쉬운 5개**: 13, 30 (★) / 3, 22, 23 (★★, 데이터 자급자족)
**가장 강한 증거가 나오는 5개**: 1, 4, 5, 25, 28 (전후 비교 실험이 가능)
