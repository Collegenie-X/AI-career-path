### 여기서 읽히는 패턴 (중요)
1. **주제 규모가 작다.** "기후 위기 해결" 같은 거대 담론이 아니라 *딸기 가격*, *점심 메뉴*, *벌레 물린 자국*이다.
2. **본인 반경 3m 안의 문제**다. 동생 울음, 급식, 스마트폰 앱 권한, 검색 기록.
3. **AI 유형이 4가지로 수렴한다.**
   - 이미지 분류 (벌레자국, 얼굴, 표정)
   - 음성/소리 분류 (아기 울음)
   - 수치 예측 (딸기 가격)
   - 추천·개인화 (점심 메뉴, 검색 이력)
   → 중학생이 10주 안에 **프로토타입까지 만들 수 있는** 난이도.
4. **"측정 기준"을 스스로 정의해야 한다.** 포스터 세션 질문이
   *"이 데이터는 어디서 구했죠?" "정상이 아니라는 기준은 무슨 근거죠?"* 였다.
   → 아이디어보다 **데이터 출처와 판단 기준의 근거**를 파고든다.

## PART 3. 승부 전략 정리

### 아이템 고르는 공식
```
[내가 실제로 겪은 불편]  ×  [측정 가능한 데이터]  ×  [AI 4대 유형 중 하나]
```
- 실제 겪은 불편 → 발표에서 "왜 이걸 했나"에 진심이 실린다 (열정·태도 점수)
- 측정 가능한 데이터 → "데이터 어디서 구했죠?" 질문에 답이 된다
- AI 4대 유형(이미지분류 / 소리분류 / 수치예측 / 추천) → 10주 내 구현 가능

### 잘 먹히는 5개 테마 (수상작 역산)
1. **디지털 안전·프라이버시** — 앱 권한, 개인정보 마스킹, 악플 탐지 *(가장 강함)*
2. **돌봄·약자 지원** — 아기 울음, 시각장애인, 노인
3. **생활 예측** — 농산물 가격, 대기줄, 급식 잔반
4. **건강·안전 진단** — 벌레 물린 자국, 피부, 자세
5. **뉴스 속 사고 예방** — 맨홀, 지진, 화재

### 피해야 할 것
- "AI로 환경 문제 해결" 같이 **범위가 무한한 주제** → 10주 안에 산출물이 안 나온다
- 데이터를 구할 수 없는 주제 → 포스터 세션에서 무너진다
- 이미 흔한 것(단순 챗봇, 번역기) → *참신성* 항목에서 감점

### 발표에서 준비해야 할 3문답 (실제로 나온 질문)
1. "이 데이터는 어디서 구한 것이죠?"
2. "이게 정상이 아니라는 **기준**은 무슨 근거로 정한 것이죠?"
3. "이 주제를 잡은 이유는 무엇인가요?"

## 4-3. ★ 예선 채점표 (100점 만점) — 이 대회의 핵심

2026년부터 예선이 **"창업 아이디어 포트폴리오" 제출** 방식으로 운영된다.
지원자가 **중학생 시절 직접 구상하거나 제작한 / 사업화를 시도한** 아이디어를 양식에 맞춰 작성.
작성 항목: **해결하려는 문제 · 구체적 해결방안 · 차별성 · 주요 사용자 · 발전 가능성**.
실제 제작·실행한 결과물이 있으면 **이미지나 영상 링크를 답변란에 첨부 가능**.

| 배점 | 항목 | 무엇을 보는가 |
|---|---|---|
| 20 | **문제 발견 및 사용자 이해** | 문제가 분명한가, 주요 사용자와 불편 상황이 구체적인가 |
| 20 | **아이디어의 창의성·차별성** | 기존 방식 대비 새로운 관점·차별 요소가 있는가 |
| 20 | **해결방안의 구체성·완성도** | 핵심 기능·구성·이용 방식이 구체적으로 제시됐는가 |
| 20 | **실제 제작·실행·검증 경험** | 시제품, 스케치, 화면 설계, **설문·인터뷰**, 시연 영상 등 직접 한 흔적 |
| 20 | **사업화·발전 가능성** | 사용자, 활용 장면, 확장 방향, **수익화/운영 가능성**이 현실감 있는가 |

주최 측이 명시한 원칙:
> **"결과물의 완성도만으로 평가하지 않으며, 아이디어를 실제로 구체화하고 발전시켜 본 과정과 실행 흔적을 중요하게 반영함"**

### 동점자 처리 순서 = 사실상 항목 우선순위
1. **실제 제작·실행·검증 경험** 점수 높은 자
2. 아이디어의 창의성·차별성
3. 문제 발견 및 사용자 이해
4. 생년월일이 늦은 자(저연령 우대)

> **해석**: 5개 항목 배점은 같지만 **동점 1순위가 '실행 흔적'** 이다.
> 아이디어만 예쁘게 쓴 포트폴리오는 진다. **설문 30명 돌린 캡처 한 장, 종이 프로토타입 사진, 3분 시연 영상**이 순위를 가른다.
> 그리고 **저연령 우대**가 명시돼 있으므로 **중2가 중3보다 동점 시 유리**하다.

## 4-5. 이 대회 공략법 (채점표 역산)

**예선 (포트폴리오)**
- 5개 항목이 각 20점 → **5개 문단을 균등하게** 채운다. 한 항목이라도 비면 20점이 날아간다.
- 최우선 투자처는 **'실행 흔적'**: 구글폼 설문 결과 그래프 / 손그림 와이어프레임 / 앱 화면 목업 / 인터뷰 3인 메모 / 1분 시연 영상 링크. 동점 1순위 항목이다.
- **수익화 모델**을 반드시 한 줄이라도 쓴다 (사업화 가능성 20점). AI 대회와 가장 다른 지점 — 여긴 *창업* 대회다.
- 소재는 **"중학생 시절 직접 구상/제작/사업화 시도한 것"** 이라고 명시 → 학교 동아리·자유학기제 프로젝트·개인 사이드 프로젝트를 그대로 써도 된다.

**본선 (현장 승부)**
- 제시 주제는 당일 공개 → 아이템 암기가 아니라 **사업계획서 골격 암기**가 무기다.
  권장 10장 구성: `문제 → 대상 사용자 → 기존 해결책의 한계 → 우리 아이디어 → 핵심 기능 3개 → 사용 시나리오 → 차별점 → 수익 모델 → 확장 계획 → 정리`
- 2시간에 10장. **장당 12분**. 디자인 버리고 문장으로 채운다(디자인 미심사 명시).
- AI·템플릿 금지이므로 **기본 PPT 도형만으로 5분 발표**하는 연습을 미리 해둘 것.
- 오후 질의응답 대비: "그래서 누가 돈을 내나요?" "이미 있는 서비스와 뭐가 다르죠?" 두 질문은 반드시 나온다.
