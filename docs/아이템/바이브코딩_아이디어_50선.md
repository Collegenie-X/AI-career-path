> 기준: **주말 2일 안에 혼자 만들 수 있는 것**. 브라우저에서 도는 웹앱 또는 노코드/로우코드 앱.
> 각 항목은 `문제 → 만드는 것 → 데이터 → 난이도` 순. 난이도 ★=반나절, ★★=1~2일, ★★★=1~2주.
> 조사 근거: LG AI 청소년 캠프 실제 프로젝트, 삼성 주니어 SW 창작대회 수상작, 한국코드페어 심사구조 (2026-09 조사)

## 9. 바이브 코딩 실전 가이드

### 스택 — 이거면 끝난다
| 목적 | 도구 | 이유 |
|---|---|---|
| 웹앱 뼈대 | **HTML 한 파일 + JS** | 서버 없이 브라우저에서 바로 실행, 배포 쉬움 |
| 배포 | GitHub Pages / Netlify Drop | 무료, 링크 하나 나옴 → **포트폴리오에 붙일 URL** |
| 데이터 저장 | localStorage → 필요시 Firebase | 로그인·서버 없이 시작 |
| 이미지 인식 | **Teachable Machine**(구글) | 사진 30장씩 드래그하면 모델 완성. 코딩 0줄 |
| 소리 분류 | Teachable Machine 오디오 모드 | 아기 울음·소음 분류에 그대로 씀 |
| 지도 | Leaflet + OpenStreetMap | 무료, API 키 불필요 |
| 공공데이터 | data.go.kr, 나이스 교육정보 개방포털, KAMIS | 무료 신청 |
| 앱처럼 만들기 | PWA(홈화면 추가) | 앱스토어 등록 없이 "앱" 됨 |

### 하루 만에 만드는 순서
```
1) 종이에 화면 3장 그리기 (입력 → 처리 → 결과)   … 30분
2) AI에게 "이 화면 3장짜리 단일 HTML 파일로 만들어줘" … 1시간
3) 내 데이터로 바꿔치기 (샘플 → 진짜 데이터)      … 2시간
4) 친구 5명에게 보여주고 한 줄씩 피드백 받기        … 1시간  ← 점수의 핵심
5) 피드백 2개 반영 + 시연 영상 2분 녹화            … 1시간
```

### 제출물에 반드시 넣을 5종
1. **작동하는 링크** (배포 URL)
2. **시연 영상 1~2분** — 대부분 대회가 2분 이내 제한
3. **사용자 피드백 캡처** — 구글폼 설문 결과 그래프. *디미고 동점자 1순위 항목*
4. **개선 전/후 화면 비교** — "발전시켜 본 과정" 증거
5. **손그림 초안 사진** — 처음 종이 스케치. 진짜 내가 했다는 증거

### 대회별 AI 사용 규칙 (틀리면 실격)
| 대회 | 규칙 |
|---|---|
| LG AI 청소년 캠프 | AI 도구 사용 **가능**, 단 **어떻게 썼는지 영상에서 밝힐 것** |
| 디미고 창업아이디어 **본선** | 현장 **AI 전면 금지** (ChatGPT·Perplexity·Copilot·Canva·미리캔버스). 폰트 설치도 금지 |
| 한국코드페어 | 핵심 소스코드 제출 항목 있음 → **설명 못 하는 코드는 넣지 말 것** |

> 바이브 코딩으로 만들되, **모든 줄을 설명할 수 있어야 한다.**
> 포스터 세션·질의응답에서 실제로 나온 질문:
> *"이 데이터는 어디서 구했죠?" / "정상이 아니라는 기준은 무슨 근거죠?" / "이 주제를 잡은 이유는?"*

## 10. 아이디어 고를 때 체크리스트

- [ ] 내가 **직접 겪은** 불편인가? (아니면 발표에서 티가 난다)
- [ ] 사용자를 **오늘 당장 5명** 찾을 수 있는가? (같은 반 = 최고의 사용자)
- [ ] 데이터를 **무료로** 구할 수 있는가? (공공API / 내가 직접 수집)
- [ ] 판정 기준을 **한 문장으로** 말할 수 있는가? ("3일 이상 기록이 없으면 이상")
- [ ] 주말 안에 **화면 3장**으로 줄일 수 있는가?
- [ ] 이미 흔한 것(단순 챗봇·번역기·투두앱)이 **아닌가**?

### 피해야 할 5가지
1. "AI로 환경 문제 해결" 류의 **범위 무한** 주제
2. 데이터를 구할 수 없는 주제 (의료 진단, 실시간 교통량 원본)
3. 기능 10개짜리 기획 — 3개로 줄여야 완성된다
