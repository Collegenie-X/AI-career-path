# 한국 공교육 IB 도입 현황 (2026년 기준)

> **2026.10 업데이트:** IB 수업·프로젝트 방식(2-6), 논·서술형에 강한 이유(2-7), 사고관의 전환(2-8), IB vs KB(2-9), 초·중·고 대표 IB 학교와 IB 벨트(3-0), 학교 선택 시 IB 연차의 중요성(3-0-1), 경기외고 고성적 요인 분석(3-2), 표선고 케이스 스터디(3-4) 추가

## 먼저 알아야 할 핵심 용어

> IB 관련 문서를 읽기 전에 아래 용어를 먼저 이해하면 전체 흐름이 쉽게 잡힙니다.

### IB 기본 용어

| 용어 | 뜻 | 쉽게 말하면 |
|------|-----|-----------|
| **IB** (International Baccalaureate) | 국제 바칼로레아. 스위스 IBO가 운영하는 국제 교육 프로그램 | 전 세계 공통 교육과정 (한국 교육과정과 별개) |
| **IBO** (IB Organization) | IB를 만들고 관리하는 스위스 본부 기관 | IB의 "교육부" 역할 |
| **IB 월드스쿨** (IB World School) | IBO로부터 최종 인증을 받은 학교 | "IB 정식 운영 학교" = 인증학교 |

### IB 프로그램 종류 (학교급별)

```mermaid
graph LR
    A["🏫 PYP<br/>초등학교 과정<br/>(Primary Years Programme)<br/>초1~초6"] --> B["🏫 MYP<br/>중학교 과정<br/>(Middle Years Programme)<br/>중1~중3"]
    B --> C["🏫 DP<br/>고등학교 과정<br/>(Diploma Programme)<br/>고1~고2, 2년"]
```

| 약어 | 정식 명칭 | 대상 | 핵심 |
|------|----------|------|------|
| **PYP** | Primary Years Programme | 초등학교 (3~12세) | 탐구 중심 학습, 주제 통합 수업 |
| **MYP** | Middle Years Programme | 중학교 (11~16세) | 교과 간 연결, 개념 기반 학습 |
| **DP** | Diploma Programme | 고등학교 (16~19세, 2년) | 6과목 + TOK/EE/CAS, 최대 45점, **국제 공인 학력** |

> **"DP 인증학교"** = IBO로부터 고등학교 과정(DP)을 정식 운영할 수 있다고 인증받은 학교.
> 같은 학교라도 PYP만 인증받고 MYP/DP는 아직인 경우가 있으므로, **어떤 프로그램의 인증인지**가 중요합니다.

### IB 학교 인증 단계 (3단계)

학교가 IB를 도입하려면 IBO의 심사를 거쳐 단계별로 승격됩니다.

```mermaid
        C["3단계: 인증학교<br/>(IB World School)<br/>──────────<br/>• IBO 심사단 방문 통과<br/>• IB 정식 운영<br/>• 5년마다 재평가"]
```

| 단계 | 한국어 | 영어 | 의미 | IB 수업 가능? |
|------|--------|------|------|:------------:|
| **1단계** | 관심학교 | Interested School | IB를 알아보고 준비하는 중 | ❌ 불가 |
| **2단계** | 후보학교 | Candidate School | IB 수업을 시범 적용하며 인증 준비 중 | ⚠️ 시범만 가능 |
| **3단계** | 인증학교 (= 월드스쿨) | Authorized School (= IB World School) | IBO가 공식 인증한 정식 IB 학교 | ✅ 정식 운영 |

> **핵심 포인트:** "IB 학교"라고 해서 모두 같은 수준이 아닙니다.
> - **관심학교 106교** ≠ IB 수업을 하는 학교 106교
> - **인증학교(월드스쿨)만** IB 디플로마를 발급할 수 있는 정식 IB 학교입니다
> - 뉴스에서 "IB 학교 225교"라고 하면 관심+후보+인증을 모두 합친 숫자입니다

### DP 수업에서 나오는 용어

| 용어 | 뜻 | 쉽게 말하면 |
|------|-----|-----------|
| **HL** (Higher Level) | 심화 수준 과목 (240시간) | 깊이 배우는 과목 (3~4과목 선택) |
| **SL** (Standard Level) | 표준 수준 과목 (150시간) | 기본 수준으로 배우는 과목 |
| **TOK** (Theory of Knowledge) | 지식이론 — 지식의 본질을 탐구 | "우리가 아는 것을 어떻게 아는가?" 철학 수업 |
| **EE** (Extended Essay) | 확장 에세이 — 4,000단어 연구 논문 | 대학 졸업논문의 고등학생 버전 |
| **CAS** (Creativity, Activity, Service) | 창의·활동·봉사 프로젝트 | 18개월간 봉사+운동+창작 활동 필수 |
| **IA** (Internal Assessment) | 내부평가 — 교사가 채점, IBO가 검증 | 실험보고서, 구술발표, 연구과제 등 |
| **EA** (External Assessment) | 외부평가 — IBO 본부가 출제·채점 | IB 최종 시험 (논술형) |
| **IB 디플로마** | IB DP 과정 수료 증서 | 총 24점 이상 + 모든 조건 충족 시 발급되는 국제 공인 학력 |

## 1. IB 인증 3단계


| 단계 | 명칭 | 소요 기간 | 주요 요건 |
|------|------|----------|----------|
| **1단계** | 관심학교 (Interested School) | 3~6개월 | IB 프로그램 탐색, IB 리더십팀 조직, 전문적 학습공동체 운영, IB 평가자의 준비 상태 평가 통과 |
| **2단계** | 후보학교 (Candidate School) | 최소 1년~최대 2년 | IB 수업·평가 적용, 전 교원 IB 워크숍 참여, IBO 컨설턴트 대면·비대면 컨설팅 수용, 학습 운영 과제 실천 |
| **3단계** | 인증학교 (Authorized School / World School) | 심사단 방문 평가 후 | IB 프로그램 전면 도입·운영, IBO 심사단 방문 평가 통과, 공식 IB 월드스쿨 자격 획득 |

> 관심학교부터 인증학교까지 전체 과정은 약 **2~4년** 소요

## 2. IB DP(고등학교 과정) 수업 방식

### 2-1. 과목 구성: 6개 과목군 + 3개 핵심 과정

| 과목군 | 영역 | 과목 예시 |
|--------|------|----------|
| Group 1 | 언어와 문학 (Studies in Language & Literature) | 한국어 A, 영어 A |
| Group 2 | 언어 습득 (Language Acquisition) | 영어 B, 중국어, 일본어 |
| Group 3 | 개인과 사회 (Individuals & Societies) | 경제학, 역사, 경영학, 심리학 |
| Group 4 | 과학 (Sciences) | 물리학, 화학, 생물학, 컴퓨터과학 |
| Group 5 | 수학 (Mathematics) | 수학 AA(분석과 접근), 수학 AI(응용과 해석) |
| Group 6 | 예술 (The Arts) | 미술, 음악, 연극 (또는 Group 1~4에서 추가 선택 가능) |

- 6과목 중 **3~4과목은 HL(Higher Level, 240시간)**, 나머지는 **SL(Standard Level, 150시간)**
- 각 과목 **최대 7점**, 6과목 합산 **최대 42점**

### 2-2. 핵심 과정 (Core Components)

| 핵심 과정 | 내용 | 평가 방식 | 배점 |
|----------|------|----------|------|
| **TOK** (Theory of Knowledge, 지식이론) | 지식의 본질과 인식 방법을 탐구하는 철학적 수업 (100시간) | 에세이 1편 + 전시회(Exhibition) | 최대 3점 (EE와 합산) |
| **EE** (Extended Essay, 확장에세이) | 학생이 선택한 주제로 독립 연구, 4,000단어 논문 작성 | 외부 평가(IBO 채점) | TOK와 합산하여 최대 3점 |
| **CAS** (Creativity, Activity, Service) | 창의성·신체활동·봉사 프로젝트 수행 (18개월간) | 이수/미이수 (미이수 시 디플로마 불가) | - |

**총점: 과목 42점 + 핵심 3점 = 최대 45점**

### 2-3. 디플로마 미수여 조건 (Failing Conditions)

다음 중 하나라도 해당하면 IB 디플로마가 수여되지 않습니다:

| 조건 | 설명 |
|------|------|
| 총점 24점 미만 | 6과목 + 보너스 합산 24점 이상 필요 |
| 과목 1점 | 어떤 과목이든 1점을 받으면 불가 |
| 3과목 이상 3점 이하 | HL/SL 무관 |
| CAS 미완료 | 18개월간 창의·활동·봉사 포트폴리오 필수 |
| TOK 또는 EE에서 E등급 | 최저 등급 시 불가 |
| 표절 적발 | 학문적 정직성 위반 시 불가 |

### 2-4. 평가 방식

| 구분 | 내용 | 비율 |
|------|------|------|
| **외부평가 (EA)** | IBO 본부 출제·채점, 5월 시행, 과목당 2~3개 시험지, 서술형·분석형 중심 | 약 70~80% |
| **내부평가 (IA)** | 교사 평가 → IBO 조정. 과학: 실험보고서, 수학: 수학적 탐구, 영어: 구술발표, 경제: 기사분석 | 약 20~30% (예술 35~50%) |

### 2-5. 한국 일반고 vs IB DP 수업 비교

| 비교 항목 | 한국 일반고 | IB DP |
|----------|-----------|-------|
| **수업 방식** | 강의 중심, 교과서 기반 | 토론·탐구·프로젝트 중심 |
| **평가 방식** | 객관식+단답형, 상대평가(내신 등급) | 논술형·서술형, 절대평가(1~7점) |
| **교육과정** | 3년 (고1~고3) | 2년 (pre-DP 1년 + DP 2년) |
| **시험 출제** | 학교 자체 출제 | IBO 본부 출제 (외부평가) |
| **성적 인증** | 국내 내신 등급 | IB 디플로마 (국제 공인 학력) |
| **핵심 역량** | 교과 지식 암기·적용 | 비판적 사고, 연구 능력, 자기주도 학습 |

### 2-6. IB 수업은 실제로 어떻게 진행되나 — 탐구·프로젝트 수업의 실제

> IB 수업의 단위는 "진도"가 아니라 **"탐구 단원(Unit of Inquiry)"** 입니다. 한 단원은 보통 3~6주이며, 교사가 설명하고 학생이 받아 적는 시간보다 **학생이 질문하고, 조사하고, 쓰고, 말하고, 고치는 시간**이 훨씬 깁니다.

#### (1) 한 단원이 굴러가는 6단계 사이클

```mermaid
graph LR
    A["① 탐구 질문<br/>(Inquiry Question)<br/>개념·맥락 제시"] --> B["② 조사·실험<br/>자료·데이터 수집"]
    B --> C["③ 토론·협업<br/>근거 비교, 반론"]
    C --> D["④ 산출물<br/>에세이·보고서·발표"]
    D --> E["⑤ 피드백<br/>루브릭 기반 교사·동료 피드백"]
    E --> F["⑥ 성찰·수정<br/>초안 → 최종본"]
    F -.다음 단원 질문으로.-> A
```

| 단계 | 교실에서 실제로 하는 일 | 교사의 역할 |
|------|----------------------|-----------|
| ① 탐구 질문 | "기후 위기 책임은 누구에게 더 있는가?"처럼 **정답이 하나가 아닌 질문**으로 시작 | 핵심 개념(Key Concept)·글로벌 맥락 제시 |
| ② 조사·실험 | 1차·2차 자료, 통계, 실험 데이터 수집 | 자료 신뢰도 판단법 코칭 |
| ③ 토론·협업 | 조별로 근거를 비교하고 **반론을 스스로 세움** | 질문으로 사고를 밀어붙이는 퍼실리테이터 |
| ④ 산출물 | 에세이, 실험보고서, 구술 발표, 포스터, 전시 | 평가 기준(Criteria) 사전 공개 |
| ⑤ 피드백 | 루브릭 항목별 피드백 (점수보다 코멘트 중심) | 1:1 컨퍼런스 |
| ⑥ 성찰·수정 | 성찰 일지 작성, 초안 수정 후 최종 제출 | 과정 기록 검토 (학문적 정직성 확인) |

#### (2) IB 수업 6대 교수 원칙 (ATT, Approaches to Teaching)

| 원칙 | 의미 | 교실 장면 예시 |
|------|------|-------------|
| 탐구 기반 | 질문에서 출발 | 교사가 공식을 주기 전에 학생이 데이터에서 규칙을 먼저 찾음 |
| 개념 이해 중심 | 사실보다 개념 | "변화", "관계", "체계" 같은 개념으로 과목을 연결 |
| 지역·세계 맥락 | 내 동네 → 세계 | 제주 해양쓰레기 → SDG 14로 확장 |
| 협업 | 팀 단위 탐구 | 조별 실험 설계, 동료 평가 |
| 개별화 | 학생마다 다른 도달 경로 | 같은 IA라도 주제는 학생마다 다름 |
| 평가 정보 활용 | 평가가 곧 학습 | 형성평가 결과로 다음 수업 조정 |

#### (3) 실제 수업 사례 (국내 공교육 IB)

| 학교 | 과목 | 수업 장면 |
|------|------|---------|
| 경북대사대부고 | **TOK** | 여러 종류의 지도(메르카토르 도법, 시대별 지도 등)를 비교 → "왜 지도마다 다를까?" → 정확성의 한계, 시대 권력이 지식에 반영되는 방식을 토론 |
| 경북대사대부고 | **수학** | 미적분 개념을 바탕으로 조별로 **'미적분 밈(meme)'을 제작·발표** → 다른 조 밈의 개념 오류를 서로 평가 |
| 표선고 | **EE·CAS** | 표선면 지역사회·공동체를 소재로 한 봉사·탐구 프로젝트를 소논문(EE)·1개월 이상 협업 프로젝트(CAS)로 연결 |

### 2-7. 왜 IB 학생은 논·서술형에 강한가

IB DP의 모든 평가는 **객관식 0%**입니다. 2년 동안 학생이 쓰는 글의 총량이 일반고와 비교가 되지 않습니다.

| 항목 | 일반고 (3년) | IB DP (2년) |
|------|-----------|-----------|
| 장문 글쓰기 (1,000자+) | 수행평가 일부 | IA 6편 + EE 1편 + TOK 에세이 1편 + 과목별 에세이 수십 편 |
| 최장 글 | 보통 2,000~3,000자 내외 | **EE 4,000단어 (한국어 약 1만 자 이상)** |
| 구술 평가 | 거의 없음 | 언어 과목 구술, TOK 발표, EE 최종 면담(viva) |
| 초안 → 피드백 → 수정 | 드묾 | **모든 IA·EE에 의무적으로 내장** |
| 채점 기준 공개 | 학교마다 다름 | **루브릭(Criteria)을 사전 공개** — 학생이 기준을 보고 씀 |

**IB 학생이 논·서술형에 강해지는 5가지 메커니즘**

| # | 메커니즘 | 설명 |
|---|---------|------|
| 1 | **루브릭 내면화** | 매번 "주장–근거–분석–평가–결론" 기준표로 채점받다 보니, 시험장에서도 채점자의 눈으로 자기 답안을 설계 |
| 2 | **명령어(Command Term) 훈련** | IB는 "설명하라(explain)", "평가하라(evaluate)", "논하라(discuss)", "비교하라(compare)"의 요구 수준을 구분해 가르침 → 문제가 무엇을 요구하는지 정확히 읽음 |
| 3 | **반론 의무화** | TOK·EE·역사·경제 에세이 모두 반대 관점(counterclaim)을 다루지 않으면 상위 점수가 불가 |
| 4 | **분량 체력** | 4,000단어 논문을 1년 넘게 다듬은 학생에게 1,000자 서술형은 부담이 아님 |
| 5 | **과정 증빙** | 초안·성찰 기록·구술 면담으로 "내가 쓴 글"임을 증명 → AI 대필이 통하지 않는 구조라 실제 쓰기 능력이 길러짐 |

> **2028 이후 의미:** 2028 대입 개편으로 고교 내신 서·논술형 평가가 확대되고, 대구 KB 등 교육청 차원의 논·서술형 평가가 시작되고 있습니다. IB 학생은 이 변화의 **"이미 2년을 미리 훈련한 집단"** 입니다.

### 2-8. 사고관의 전환 — "정답 찾기"에서 "프로세스 설계"로

IB를 2년 이상 경험한 학생에게서 공통으로 관찰되는 변화는 성적보다 **사고 방식**입니다.

```mermaid
graph LR
    subgraph "Before — 결과 중심 사고"
        A1["정답이 무엇인가?"] --> A2["외우고 빨리 푼다"] --> A3["점수 = 결과"]
    end
    subgraph "After — 프로세스 중심 사고"
        B1["어떤 질문을 던질까?"] --> B2["어떤 근거·방법으로 검증할까?"] --> B3["반론은 무엇이고 한계는?"] --> B4["무엇을 고칠까? (성찰)"]
    end
    A3 -.IB 2년.-> B1
```

| 구분 | 결과 중심 (기존) | 프로세스 중심 (IB 이후) |
|------|---------------|---------------------|
| 출발점 | 주어진 문제 | **내가 만든 탐구 질문** |
| 성공 기준 | 정답 맞히기 | 근거의 질, 방법의 타당성, 한계 인식 |
| 실패의 의미 | 감점 | **다음 초안의 재료** (피드백 → 수정) |
| 시간 관리 | 시험 직전 몰아치기 | 12~18개월 장기 프로젝트 역산 계획 |
| AI 활용 | 답을 받아 적음 | 자료 조사·반론 점검용으로 쓰고, 논증은 직접 |
| 생기부에 남는 것 | "~를 이해함" | "~라는 질문을 세우고, ~ 방법으로 검증하고, ~ 한계를 발견해 수정함" |

> **입학사정관 관점:** 학종 서류에서 IB 학생의 세특이 강한 이유는 결과가 아니라 **"질문 → 방법 → 한계 → 수정"의 프로세스가 문장으로 남기 때문**입니다. 면접에서도 "왜 그 방법을 택했나?", "한계는?"이라는 질문에 자기 언어로 답할 수 있습니다.

| 누가 유리한가 | 지금 중학생 중 해외대·학종 지향, 글쓰기 체력 있는 학생 | 일반고 진학생 전체 (평가 방식 변화로 간접 영향) |

**공통점 — 왜 같이 봐야 하나:** 둘 다 "정답 암기"에서 **"근거를 세우는 글쓰기와 과정 평가"** 로 간다는 방향이 같습니다. KB는 IB의 수업·평가 철학을 국가 교육과정 안으로 옮기려는 시도이므로, **IB 학교의 경험(특히 연차가 쌓인 학교의 코칭 노하우)이 KB의 원형**이 됩니다.

### 3-0-1. 학교를 고를 때 "IB 연차"를 반드시 봐야 하는 이유

> **IB는 인증을 받았다고 바로 완성되는 교육이 아닙니다.** 프로젝트형 교육은 **졸업생을 배출할 때마다 교사의 코칭 노하우가 누적**되기 때문에, 연차가 쌓인 학교일수록 IA·EE·TOK 지도의 질이 확연히 높아집니다.

**연차가 쌓이면 무엇이 쌓이나**

| 누적 자산 | 1~2기 학교 | 5기 이상 학교 |
|----------|----------|------------|
| **IA·EE 모범 사례 아카이브** | 없음 — 교사도 처음 지도 | 점수대별 실제 학생 산출물 보유 → "이 정도 쓰면 몇 점" 감각 |
| **IBO 채점 조정(Moderation) 피드백** | 1~2회 | 매년 IBO가 교사 채점을 조정한 데이터 누적 → 교내 채점이 IBO 기준과 일치 |

#### 경기외고는 왜 IB 성적이 압도적으로 높은가 — 6가지 요인

> 경기외고의 평균 38~39점대는 세계 평균(약 29~30점)보다 9점 가까이 높습니다. 이는 **"IB가 좋아서"** 하나로 설명되지 않으며, **선발 효과 + 연차 효과 + 운영 구조**가 겹친 결과입니다. 상담 시에는 이 세 가지를 구분해서 설명해야 합니다.

| # | 요인 | 구분 | 설명 |
|---|------|------|------|
| 1 | **15년 누적 연차** | 연차 효과 | 2011년 도입 이후 10기 이상 졸업생 배출. IA·EE 점수대별 산출물 아카이브, IBO 채점 조정 피드백, 교사의 채점관 경험이 축적 → 교내 코칭이 IBO 채점 기준과 거의 일치 |
| 2 | **2단계 선발** | 선발 효과 | ① 외고 자기주도학습전형(영어 내신·면접)으로 1차 선발 → ② 교내에서 IB반 희망자를 다시 선발. 학년당 약 30~50명의 **영어 학술 글쓰기 상위 집단** |
| 3 | **영어 DP** | 운영 구조 | 영어로 DP를 이수 → 해외대 지원에 IB 점수를 그대로 사용. 목표(해외 명문대)와 평가(IB 점수)가 일치해 학생 동기가 IB 점수에 집중됨 |

##### ① 왜 표선고였나 — 도입 배경과 경과

농어촌 지역 공립 일반고로, 성적 상위권 학생이 제주시·도외로 빠져나가며 학교 경쟁력이 약해지던 상황이었습니다. 학교는 **"평가 방식을 바꾸지 않으면 수업이 바뀌지 않는다"** 는 문제의식에서 IB를 탐색했습니다.

```mermaid
    title 표선고 IB 도입 경과
    2015 무렵 : 평가 방식 문제의식 — IB 탐색 시작
    2019 : 제주도교육청–IBO 협약(MOU), 한국어 IB 도입 공식화
    2020 : IB DP 후보학교 승인
    2021.11 : IB DP 월드스쿨 인증 (전교생 이수 모델)
```

##### ③ 수업 방식 — 3축 체제

수능 문제풀이식 수업을 **완전히 배제**하고, 학교 전체가 탐구·논술·서술·구술 중심으로 운영됩니다.

| 축 | 내용 |
|----|------|
| **1축 · IB DP 정규 수업** | 6과목(HL 3 + SL 3) — 모든 과목이 토론·탐구·서술 평가. 고1은 Pre-DP(탐구 기초·글쓰기 적응), 고2~3이 정식 DP 2년 |
| **2축 · IA·EE 개별 탐구** | 과목별 IA + EE 4,000단어 소논문 — **지도교사 1:1 매칭**. 고1에 주제 탐색, 고2부터 본격 집필 |
| **3축 · CAS 협업 프로젝트** | 1개월 이상 팀 프로젝트 — 표선면 지역사회·공동체 연계 봉사·탐구 |

**재학생 하루 일과 (예시)**

| 시간 | 활동 |
|------|------|
| 08:30–12:30 | IB DP 정규 수업 (논·서술 중심) |
| 12:30–13:30 | 점심 + 친구들과 IA·EE 진행 상황 공유 |
| 13:30–16:30 | 오후 수업 (TOK·과학 실험·HL 심화) |
| 16:30–18:00 | CAS 프로젝트·동아리·운동 |
| 19:00–22:00 | 기숙사 자율학습 — IA 작성·EE 자료조사·에세이 |

> 주변에 학원이 거의 없어 **사교육 의존도가 매우 낮습니다.** 학습의 절반은 교내 자율학습과 교사 피드백으로 이뤄집니다.

##### ④ "수능 없이" 대학에 간 경로

표선고 학생들은 **수능 최저학력기준이 없는 학생부종합전형(학종)** 을 주력으로 대학에 진학했습니다. IB 수업에는 수능 문제풀이 시간이 없기 때문에, 처음부터 정시·수능최저 전형이 아니라 **학생부(내신 + 세특)** 로 승부하는 구조입니다.

```mermaid
graph LR
    A["IB 수업·평가<br/>IA · EE · TOK · CAS"] --> B["학교생활기록부<br/>세특·창체에 탐구 과정 기록"]
    C["학교 내신<br/>(IB 수업 기반 평가)"] --> B
    B --> D["수능 최저 없는<br/>학생부종합전형"]
    D --> E["서울대·연세대·고려대<br/>KAIST·UNIST·DGIST"]
    A --> F["IB 디플로마 점수<br/>(1월 발표)"]
    F --> G["해외 대학<br/>(일본 등)"]
    style D fill:#b7f9c4,color:#333
```

| 단계 | 핵심 |
|------|------|
| 국내 수시 원서 (9월) | IB 점수는 아직 없음 → **학생부만으로 평가**. IB 점수(45점)는 국내 대입 전형자료가 아님 |
| 학생부의 강점 | EE·IA·TOK 탐구가 세특에 "질문 → 방법 → 한계 → 수정"의 과정으로 기록됨 |
| 면접 | 4,000단어 논문을 직접 쓴 경험 → "왜 그 주제를, 어떤 방법으로, 한계는?"에 자기 언어로 답변 |
| 추가 무기 | 농어촌 지역 거주 요건을 충족하면 **농어촌 특별전형** 지원 가능 |
| 해외대 | IB 디플로마 점수로 직접 지원 (1기: 일본 도쿄농업대·소카대 합격) |

> ⚠️ IB 성적을 대입 전형자료로 쓸 수 있게 하는 고등교육법 개정안이 2023년 발의됐지만 시행은 확인되지 않았습니다. 2026년 현재 국내 대학에 **"IB 전형"은 따로 없으며**, IB 학생도 학생부로 똑같이 평가받습니다.
