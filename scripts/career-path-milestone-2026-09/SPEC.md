# 커리어 패스 템플릿 재작성 규격 (2026-09-28)

## 0. 왜 다시 쓰는가 (사용자 요구)

1. **커리어 패스 ≠ 커리어 실행.**
   - **커리어 패스** = 큰 최종 목표(고입 합격 · 대입 합격 · 취업/창직)를 향해 **학년별·연도별로 무엇을 준비하는가**를 적는 로드맵.
   - **커리어 실행** = 프로젝트·탐구보고서·논문·인터뷰·봉사·책·캠페인을 **주차별로 어떻게 수행하는가**. (별도 메뉴 `/dreammate`)
   - 지금 패스 템플릿은 항목 대부분이 "프로젝트 수행 절차(① ② ③, 주 몇 회 몇 분, 몇 편 몇 건)"로 쓰여 있어 실행과 구분이 안 된다. → 패스는 **준비 마일스톤**으로 다시 쓴다.
2. **실제 실현 가능해야 한다.** 실제 입시 제도·전형 일정·시험 기간·비용·연령 제한·학생의 시간을 반영한다. 환각(없는 대회·없는 학과·없는 URL)은 제거한다.

## 1. 입력/출력

- 입력: `scratchpad/in/<templateId>.json` (현재 템플릿 전체)
- 출력: `scratchpad/out/<templateId>.json` — **템플릿 전체 객체**를 다시 써서 저장 (입력의 모든 최상위 키를 유지하되 아래 규칙대로 내용을 고친 것).
- 저장 후 반드시 `python3 scratchpad/validate.py <templateId>` 를 실행해 통과시킨다.
- 저장소 파일(`frontend/data/...`)은 **절대 직접 수정하지 않는다.** out 폴더에만 쓴다.

## 2. 바꾸면 안 되는 것

`id`, `category`, `starId/starName/starEmoji/starColor`, `jobId/jobName/jobEmoji`, `authorName/authorEmoji/authorType`, `likes/uses`, `isAiGenerated/aiGeneratedNote`, `schoolType`, `universityId/departmentId`, 각 year의 `gradeId`(또는 `grade`) 값과 **year 개수·순서**.
`competencyGrowth.axes`의 6개 key와 각 axis의 levels 개수(= year 수)도 유지.

## 3. 템플릿 최상위 필드 고치기

| 필드 | 규칙 |
|---|---|
| `title` | "무엇을 목표로 하는 몇 년 패스인가"가 보이게. 수단(바이브 코딩·소논문)이 아니라 **목표(○○고 합격 / ○○계열 학종 합격 / ○○ 직무 취업)**가 주어. 사실과 다른 목표는 교정(§6). |
| `description` | 2~3문장. 최종 목표 → 학년별 준비 흐름 → "프로젝트·탐구의 세부 수행은 커리어 실행에서" 한 줄. |
| `northStar.goal` | 최종 목표 1문장(합격/취업/창직). |
| `northStar.proof` | **준비 상태 지표** 4~5개 (예: "영어 내신 4개 학기 A · 출결 무단 0 · 학교 설명회 2회 · 자기소개서 최종본 · 모의면접 5회"). 프로젝트 산출물 개수 나열 금지(대표 활동 1~2건까지만). |
| `northStar.byWhen` | 실제 전형 시점 기준 (예: "중3 12월 원서접수까지", "고3 9월 수시 원서접수까지"). |
| `northStar.ventureNote` | 유지하되 1문장으로. |
| `competencyGrowth` | evidence를 새 항목과 맞게 1줄씩 고침. stage 라벨은 새 gradeLabel의 앞부분과 일치. score는 유지 가능. |
| `aiOrchestra` | 단계 3개 유지. **미성년(중·고) 템플릿은 Claude(18세 이상 전용)를 도구로 쓰지 않는다** — ChatGPT(만 13세 이상·보호자 동의), Gemini(만 13세 이상), NotebookLM, 뤼튼, Canva, 학교 제공 계정 등으로 교체. 중1(만 12~13세)은 "보호자 계정·동의 아래" 문구를 넣는다. |
| `successStories` | 실존 인물 인용처럼 보이면 안 된다. `quote`는 "예시 시나리오"임이 드러나게 쓰고, 제도와 어긋나는 내용(일반고 자소서·입학사정관, KOI 가산점, 수상이 학종 핵심 등)은 고친다. `year`는 유지. `tips` 3개는 현실 조언으로. |
| `admissionTypeStrategies` | 있으면 §6 사실에 맞게 고침. |
| `tags`, `totalItems` | totalItems = 새 item 총수. |
| `recommendedActivities`, `schoolGuide`, `recommendedFor`, `relatedJobs`, `averageSalary`, `jobMarket` | 명백한 환각(없는 기관·없는 대회·죽은 URL 의심)만 제거. 확신 없는 URL은 지운다. |

## 4. years[] 다시 쓰기 — 핵심

각 year = `{ gradeId|grade, gradeLabel, goals[], items[] }`

### gradeLabel
"중1 — 기초 다지기"처럼 **학년(또는 N년차) — 그 해의 준비 주제**.
취업 템플릿(`step1..7`)은 **연 단위**로: 예) step1 "준비 1년차 — 직무 탐색·기초", step2 "준비 2년차 — 직무 역량·자격", step3 "준비 3년차 — 실전 경험", step4 "준비 4년차 — 지원·입사", step5~7 "입사 1~3년차". (step4가 없는 템플릿은 step3에 "실전 경험·지원"을 합친다.) 몇 개월 속성 코스로 쓰지 않는다.

### goals (year당 3~4개)
그 해가 끝났을 때의 **준비 상태**. 1문장, 60자 이내. 수치는 1개까지만.
예) "영어 내신 2개 학기 모두 성취도 A", "지원 학교 3곳 전형 요강 비교 끝", "전공 관련 대표 활동 1건 완료"

### items (year당 4~5개, 입시 학년(중3·고3)은 4개 권장)
모든 goal에 item이 1개 이상 붙어야 한다(`goalIndex`).

year마다 아래 **5개 준비 영역**에서 고르게 뽑는다 (한 year에 같은 영역 3개 이상 금지):

| 영역 | 내용 | 예 |
|---|---|---|
| A 성적·기초 | 내신·수능·직무 기초 | "국·영·수·과 내신 전 학기 성취도 A 유지" |
| B 전형·요건 | 전형 분석, 설명회, 자격·어학, 원서·서류·면접, 일정 | "10월 마이스터고 특별전형 원서접수" |
| C 학교 안 활동 | 교과 세특·동아리·진로활동·학교 봉사·임원 | "정보 동아리 1년 활동 + 학기말 발표" |
| D 대표 활동(실행 연계) | 프로젝트·탐구·인터뷰·봉사·캠페인·책 **1건** | "전공 연계 탐구 1건 완료 → 커리어 실행" |
| E 점검·방향 | 진로 탐색, 학기말 점검, 지원 전략, 독서 | "학년말 점검 — 다음 해 지원 전략 1장" |

- **D(대표 활동)는 year당 최대 1개, 입시 학년(중3·고3)과 입사 연차는 0~1개.** 템플릿 전체에서 D 비중이 30%를 넘지 않는다.
- D 항목에는 반드시 `executionRef`를 넣는다(§5). 설명에 수행 절차를 쓰지 않는다.
- 독서는 템플릿당 1~2개(E 영역). "1주제 3권 병렬 독서"는 유지하되 설명은 짧게.

### item 필드

```jsonc
{
  "type": "activity" | "award" | "portfolio" | "certification",
  "title": "45자 이내. '무엇을 언제까지' — 절차·횟수 나열 금지",
  "months": [3,4,5],            // 실제 시기. 시험·접수 일정과 맞출 것
  "difficulty": 1~5,
  "cost": "무료" | "응시료 2만원" 등 실제 수준. 학원·컨설팅비 수백만원 표기는 쓰지 않는다,
  "organizer": "학교 / 자체 / 실제 주관기관명",
  "description": "2~4문장, 120~260자. ①왜 이 시기에 이것이 목표에 필요한가 ②준비 기준(무엇이 되면 끝인가) ③현실 주의점 1개(규정·시험 기간·비용·연령·마감). 번호 매긴 절차(①②③), '주 N회 N분', 주차별 계획 금지.",
  "deliverable": "확인 가능한 결과 1줄 (예: '성적표 2장', '원서 접수증', '면접 답변 카드 20장')",
  "categoryTags": ["activity"|"project"|"award"|"paper"|"intern"|"volunteer"|"camp"|"reading"|"campaign"] 중 1~2개,
  "activitySubtype": type=activity일 때만: "project"|"intern"|"volunteer"|"camp"|"research"|"general",
  "goalIndex": 0부터, goals 인덱스,
  "priority": "must"|"boost" (선택. must는 year당 최대 2개 — 목표 달성에 실제로 결정적인 것만),
  "links": [{"title","url","kind":"official"}]  // §7 허용 목록의 URL만. 없으면 필드 생략
  "executionRef": { ... }       // D 영역만 (§5)
}
```

- `projectTrack`, `aiTools` 필드는 **넣지 않는다** (AI 도구는 aiOrchestra에서만).
- `url` 단독 필드는 쓰지 않고 `links`만 쓴다.

## 5. executionRef — 커리어 실행 연결

```json
"executionRef": {
  "form": "project",
  "label": "학교 불편 1가지를 해결하는 웹앱 1건",
  "feedId": "tpl-project-01"
}
```

- `form`: `interview` | `report` | `paper` | `book` | `volunteer` | `project` | `campaign`
- `label`: 이 패스에 맞는 주제 한 줄(40자 이내).
- `feedId`(선택): 아래 목록 중 주제가 **실제로 가까울 때만**. 억지로 맞추지 말고, 안 맞으면 생략.

## 6. 현실 사실표 (반드시 지킬 것 · 2026-09 확인)

### 고입
- **일반고**: 자기소개서·면접·입학사정관 **없음**. 평준화 지역은 지망 배정(추첨), 비평준화 지역은 중학교 내신(+출결·봉사 등 비교과 점수) 석차로 선발. 12월 원서접수(후기고). "문과/이과" 구분은 없어졌다(2022 개정 교육과정·고교학점제: 고1 공통과목 → 고2부터 과목 선택). → 일반고 목표 템플릿은 "내신·출결 관리 + 고교 선택(교육과정 편제·과학중점 등 비교) + 고1 선택과목 준비"로 쓴다.
- **영재학교(8교)**: 중3 **5월 원서접수**(2027학년도: 한국과학영재학교 5/6~13, 그 외 5/18~26) → 1단계 서류(학생기록물·자기소개서·추천서) → **2단계 영재성 검사(7월 초)** → **3단계 영재성 다면평가·캠프(8월 초·중순)** → 8월 하순 합격 발표. 중1·2도 지원 가능. 탈락해도 과학고·후기고 지원 가능.
- **과학고(20교)**: 중3 **8월 말~9월 초 원서접수** → 서류·출석/방문 면담 → **소집 면접(11월)** → 11~12월 발표. 수학·과학 내신 성취도 중심. 자기주도학습전형.
- **외고·국제고**: 후기고, **12월 초 원서접수**(서울 2027학년도 12/3~5 전후). 1단계 **영어 내신 성취도(중2-1~중3-2 네 학기, A=40점)** + 출결 → 2단계 **면접**(자기소개서·학생부 기반). 
- **자사고**: 후기고, 12월 초 원서. 서울 광역 자사고는 추첨+면접, 전국단위 자사고(민사고·하나고·외대부고·상산고 등)는 내신+면접(학교별 상이).
- **자기주도학습전형 자소서 기재 금지**: 교외 수상, **공인 어학시험 점수(TOEFL·TOEIC·TEPS 등)**, 각종 인증시험·자격증, 영재교육원 수료 여부, 올림피아드 실적, 논문·출간·특허·해외활동, 부모 직업 → 적으면 0점 처리/감점. → **외고·국제고·자사고·과학고 패스에서 TOEFL/TOEIC 응시, 올림피아드 수상을 '합격 요건'처럼 쓰지 않는다.** 실력 점검용으로 쓰더라도 "전형에 반영되지 않으며 자소서에 쓸 수 없다"를 명시. 중학생 TOEIC 800·TOEFL 80 목표 같은 항목은 삭제하거나 "영어 내신·독해력"으로 대체.
